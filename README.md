# Distribution Analysis — Histogram
**Author:** AYUSH RAJPUT  
**Track:** Veda Technology, AI & ML — Level 1, Day 27

## Objective
Create a histogram for a numerical variable and describe its concentration, spread, and possible skewness.

## Dataset
`data/student_study_hours.csv` contains illustrative study-hour values for 40 hypothetical students. It is sample data, not real student records.

## Run
```bash
pip install -r requirements.txt
python distribution_analysis.py
```
The script saves the histogram to `outputs/study_hours_histogram.png` and prints summary statistics.
